# currex

CLI на Go: курсы валют к рублю по данным ЦБ РФ и пересчёт суммы.

## Запуск

```
go run .
go run . -codes=usd,eur,kzt -amount=50000
```

## Пример

```
Курсы ЦБ РФ на 17.10.2026

Код  Валюта      Курс                 За 10 000 ₽
USD  Доллар США  1 USD = 83,6177 ₽    119,59 USD
KZT  Тенге       100 KZT = 18,4123 ₽  54 312 KZT
```

## Что сделано

- разбор XML ЦБ в кодировке windows-1251 (`golang.org/x/text`)
- обработка ошибок с обёртками и `errors.Is`
- табличный вывод через `text/tabwriter`
